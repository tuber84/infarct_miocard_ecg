# PWA для iPhone (iOS Safari)

Проект собирается как автономное прогрессивное веб-приложение (PWA): весь интерфейс, лента ЭКГ, тренажёр и 3D-модели сердца (`heart_segmented.glb` и `heart_artery_left_type.glb`, окраска в вершинах) кэшируются на устройстве через Service Worker (`sw.js`) и работают без интернета.

---

## 1. Публикация на GitHub Pages

В репозитории настроен workflow [deploy-pages.yml](../.github/workflows/deploy-pages.yml), а в настройках репозитория (**Settings → Pages → Source: GitHub Actions**) публикация уже подключена.

После каждого push в ветку `main` (или ручного запуска **Actions → Deploy PWA to GitHub Pages → Run workflow**) обновлённая сборка автоматически разворачивается по адресу:
`https://tuber84.github.io/infarct_miocard_ecg/`

Относительные пути (`base: './'`, `start_url: './'`, `import.meta.env.BASE_URL`) позволяют одинаково работать как на подпути GitHub Pages, так и в корне любого другого HTTPS-домена.

---

## 2. Установка на iPhone

1. Откройте опубликованный URL в **Safari** на iPhone (установка PWA на главный экран в iOS поддерживается из Safari; при первом открытии дождитесь полной загрузки страницы, чтобы Service Worker успел кэшировать ресурсы).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте **«КардиоАтлас ЭКГ»** с иконки на домашнем экране. В режиме установленной PWA стартовым экраном открывается **«Тренировка»** (как и в Android-приложении), а переключение в **«Атлас»** доступно в верхней панели.

---

## 3. Проверка офлайн-режима на iPhone

1. Запустите установленную иконку **«КардиоАтлас ЭКГ»** с экрана «Домой» при включённом интернете (чтобы WebKit окончательно инициализировал кэш).
2. Откройте один раз вкладку **«Атлас»** и дождитесь появления 3D-сердца (ленивый чанк `AtlasView-*.js`, `.glb` и `.webp` предзагружаются Service Worker'ом, но проверка 3D гарантирует, что WebGL и геометрия корректно работают на устройстве).
3. Включите **Авиарежим**, полностью закройте приложение (смахните из переключателя задач) и откройте снова:
   - должна открыться **«Тренировка»**, доступно прохождение этапов, ЭКГ-лента, калипер и двухпальцевый зум;
   - сохранённые попытки в `localStorage` сохраняются после перезапуска;
   - при переключении в **«Атлас»** открываются 3D-сердце, режим КАГ и все 16 сценариев (кроме внешних ссылок на сайты КР РФ, которым нужен интернет).

## 4. Обновления и ограничения iOS PWA

- **Обновление:** при сборке `vite.config.ts` автоматически вычисляет SHA-256 хэш содержимого `dist/` и меняет имя кэша (`cardioatlas-pwa-<hash>`). При открытии PWA с интернетом iOS в фоне скачивает новый `sw.js`, а после закрытия и повторного запуска приложения очищает старый кэш.
- **Безопасные отступы и жесты:** настроены `viewport-fit=cover`, CSS `env(safe-area-inset-*)`, запрет лупы выделения текста на ленте ЭКГ и подавление нативного зума страницы при жесте двумя пальцами на ленте.
- **Ограничения iOS WebKit:**
  - Если PWA **не установлена** на экран «Домой» и не открывалась в Safari несколько недель, iOS может очистить кэш и `localStorage` сайта. Для установленных на экран «Домой» приложений лимиты заметно выше, но долгосрочное хранение без резервного копирования iOS не гарантирует.
  - Внутренняя навигация по истории браузера (`pushState`) работает, однако жест свайпа от левого края экрана в standalone-режиме iOS нужно проверить на физическом iPhone рядом с горизонтальной прокруткой ленты ЭКГ.
