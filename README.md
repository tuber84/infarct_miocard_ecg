# КардиоАтлас ЭКГ — Локализатор ОКС (ИМпST / ИМбпST) и 3D-тренажёр

Локальное оффлайн веб-, десктопное (Windows `.exe`), Android-приложение (APK) и офлайн-PWA для iPhone для врачей — в первую очередь рентгенэндоваскулярных хирургов, кардиологов и реаниматологов — для наглядной отработки взаимосвязи:
**«поражение коронарной артерии → зона ишемии миокарда → 12/17-канальная ЭКГ → динамика во времени и эффект ЧКВ»**.

Поддерживает как **классический ИМ с подъёмом ST (ИМпST / STEMI)**, так и **ИМ без подъёма ST (ИМбпST / NSTEMI)** и особые паттерны при подозрении на окклюзирующее поражение (Велленс A/B, де Винтер, распространённая ишемия).

---

Медицинская основа по выбору автора — **российские клинические рекомендации 2024 года** по ИМпST и ОКСбпST (публикации 2025 года из `ref/gudelines/`). Условия сроков КАГ/ЧКВ, пороговые критерии и ссылки отображаются в клиническом разборе. ACC/AHA используются только для сравнения в [медицинском аудите](docs/MEDICAL_AUDIT_2026-11-21.md). Обновление аудита от 22.11.2026 фиксирует исправление согласованности J/ST и интервалов; клиническая валидация морфологии остаётся отдельной задачей.

Проверка независимости и сценариев: `npm run test:core`. Проверка локализатора: `npm run test:clinical`. Проверка генератора: `npm run test:ecg`. Проверка обучения: `npm run test:training`.

**Направление развития:** сначала автономный десктоп на Electron, затем мобильная версия с отдельной компоновкой и общим ядром на TypeScript. React и текущую графику сохраняем; для Android подготовлена оболочка Capacitor 8, а для iPhone — офлайн-PWA с кэшированием через Service Worker и публикацией на GitHub Pages. Архитектурные границы, этапы и критерии готовности описаны в [плане архитектуры и развития](docs/ARCHITECTURE_ROADMAP.md).

- **Android-прототип:** проект на Capacitor 8.6.2 подготовлен, отладочный APK собирается в `android/app/build/outputs/apk/debug/app-debug.apk`. Команды и требования: [сборка Android](docs/ANDROID_BUILD.md).
- **iPhone (офлайн-PWA):** развёрнута через GitHub Actions на `https://tuber84.github.io/infarct_miocard_ecg/` с полным кэшированием 3D-моделей правого и левого типов (`heart_segmented.glb`, `heart_artery_left_type.glb`) в `sw.js`. Инструкция: [PWA для iPhone](docs/IOS_PWA.md).
- Масштабирование ленты ЭКГ двумя пальцами (CSS-превью во время жеста + перерисовка на `touchend`), безопасные отступы и работа в авиарежиме прошли эмуляцию и проверки сборки; окончательное подтверждение на физических телефонах остаётся обязательным этапом.

## Возможности текущей версии

- **Узкий режим тренировки:** вкладки «Условия» / «ЭКГ» / «Ответ», горизонтальная прокрутка ленты, быстрый переход к группам отведений, калипер и масштабирование разведением или сведением двух пальцев. Жест проверен в Chromium при ширине 390 px; проверка на телефоне ещё предстоит.

- **Режим «Тренировка»:** «Дежурство №1 · Боль в груди». Пять последовательных этапов, три вопроса, разбор по российским КР, сохранение текущего этапа и последних 20 попыток на устройстве. Диагноз и результаты исследований раскрываются по ходу задачи. Подробнее — [docs/TRAINING.md](docs/TRAINING.md).

- **22 клинических сценария в трёх вкладках (`ИМпST (STEMI)`, `ОКСбпST / паттерны` и `Блокады / мимики`)**:
  - **ИМпST (9 сценариев):** `ПМЖВ (LAD)` прокс./сред./дист., `D1` («флаг ЮАР»), `ПКА (RCA)` прокс./дист., `ЗМЖВ (PDA)` (изолированный нижний ИМ от ПКА или терминальной ОВ), `ОВ (LCx) / ВТК (OM1)`, `Задний ИМ` (`ЗБВ / PLB` от ПКА или ОВ).
  - **ИМбпST и эквиваленты (7 сценариев):** `ИМбпST передне-боковой` (субэндокардиальная депрессия ST), `ИМбпST нижне-боковой` (депрессия ST + инверсия T), `ИМбпST с T↓` (глубокая симметричная инверсия T), **синдром Велленса тип A** (двухфазный `+ / −` T в `V2–V4`) и **тип B**, **паттерн де Винтера** (косовосходящая депрессия точки J + острые симметричные T и `ST↑` в `aVR`), **ствол ЛКА (`LMCA`) / 3-сосудистое поражение**.
  - **Блокады и мимики STEMI (5 сценариев):** **БЛНПГ + острый передний ИМ** (критерии Сгарбосса и модифицированный критерий Смита, `QRS 148 мс`), **неосложнённая БЛНПГ** (пропорциональная дискордантность без ОИМ), **острый перикардит** (диффузный вогнутый ST↑ + депрессия PR без Q), **синдром ранней реполяризации (СРРЖ)** (зазубрина J-точки `fish-hook`) и **синдром Такоцубо** (циркулярное апикальное баллонирование на схеме AHA при интактных КА, эволюция в гигантские T↓).
  - Плюс базовый профиль **`Норма`** (`TIMI 3`).
- **Интерактивная 3D-модель сердца и коронарных сосудов**:
  - Кликабельные точки поражения прямо на ветвях коронарного русла (с автоматической дедупликацией при совпадении сегментов для ИМбпST).
  - Визуализация степени нарушения кровотока в 3D и в КАГ:
    - **`Окклюзия · TIMI 0`** — красный 3D-тромб, серое дистальное русло и полный обрыв контраста («культя»).
    - **`Субокклюзия · TIMI 1–2`** — янтарный маркер, приглушённое русло в 3D и замедленное тусклое дистальное контрастирование в КАГ.
    - **`Крит. стеноз · TIMI 2–3`** — янтарный маркер и сохранённое прохождение контраста при ЧКВ-готовности.
    - **`ЧКВ · Стент · TIMI 3`** — металлический 3D-стент и восстановленный кровоток.
  - **Режим КАГ (С-дуга / флюороскопия):** рентген-тень сердца, **3D-ориентиры флюороскопии** (полупрозрачный позвоночник, лёгочные поля и купол диафрагмы, кнопка `Ориентиры`), селективная катетеризация (`ЛКА / ПКА / Обе`), анимация болюса контраста, **межсистемные коллатерали по Rentrop (`0–3`)** с ретроградным заполнением от контрлатерального донора при `TIMI 0`, живая индикация углов С-дуги (`LAO/RAO`, `CRA/CAU`) с двухосевой SVG-схемой трубки и детектора, 10 стандартных проекций КАГ и справочник со сравнительными таблицами.
  - **Удобная навигация и подписи:** `ЛКМ — вращать`, `ПКМ — перемещать` (панорамирование по экрану без сбивания углов С-дуги), `Колесо — зум`, кнопка **`Центр`**, а также 3-режимная кнопка подписей артерий (**`Подпись`** → **`Подписи выкл.`** → **`Все подписи`**) с мягким масштабированием по зуму (`0.7×–1.25×`).
- **Двусторонняя связь «Сосуд ↔ ЭКГ»**:
  - **ЭКГ → Артерия (обратный локализатор):** 4-шаговый клик по карточкам отведений (`1 = ST↑`, `2 = ST↓`, `3 = T↓`, `4 = сброс`) сопоставляет разметку с учебными сценариями и рекомендует дополнительные отведения (`V3R–V4R`, `V7–V9`). При недостаточных данных гипотеза отсутствует; процентов вероятности нет. Велленс B допускает вовлечение V6. Велленс A и де Винтер изучаются в пресетах; ограниченный ввод ST↑/ST↓/T↓ не позволяет автоматически различить их морфологию.
- **Учёт типа коронарного кровоснабжения**: переключатель `Правый тип` / `Левый тип` переключает реальное 3D-артериальное дерево (доминантная ОВ → ЗБВ/ЗМЖВ и гипопластичная ПКА с пологой извитой терминальной ветвью), маркеры, КАГ, ЭКГ-профиль (включая переключение `nstemi_inf` на ОВ при левом типе) и границы бассейнов ПКА/ОВ на 17-сегментной схеме AHA.
- **Bullseye AHA-17 и динамика во времени**:
  - Окраска миокарда и варианты без Q заданы условиями учебных примеров; отсутствие Q не обязательно для ИМбпST. Названия сегментов и ПЖ открываются как по наведению, так и по нажатию (тапу). Пояснения к срочности КАГ/ЧКВ и критериям ЭКГ — по российским клиническим рекомендациям 2024 года, с указанием разделов.
  - 5 стадий (`Острейшая 5–20 мин`, `Острая 20 мин – 6 ч`, `Эволюция 6–24 ч`, `Подострая 2–7 сут`, `Рубец > 1 мес`), плавный слайдер и сравнение с течением **после ранней успешной реперфузии (TIMI 3)** (с отдельными описаниями стадий для ИМпST, ИМбпST и паттерна де Винтера); интервалы стадий условные.
  - **Реалистичный рендер ЭКГ, сравнение и печать**:
    - **Монитор реального времени** (`1 / 3 канала`, `Стоп-кадр`, выбор нарушений ритма и проводимости: **`Синусовый`**, **`АВ-блок I ст. (PR 248 мс)`**, **`Мобитц I (Венкебах 4:3)`**, **`ЖЭС (PVC)`** с компенсаторной паузой, маркер реперфузионного ритма **`РИА / AIVR`**).
    - **Круг Кабрера (фронтальная плоскость)**: честный расчёт **ЭОС** (по площади `QRS` в `I`/`aVF`) и результирующего **вектора повреждения ST** по 6 фронтальным отведениям.
    - **12-канальная миллиметровая лента** (`3×4 + ритм II` и `6×2`, `10 / 5 мм/мВ`, `25 / 50 мм/с`, зум `75–160%`, полоса `+ V3R/V4R, V7–V9`, артефакты, регулировка ЧСС), **Калипер**, режим наложения **«Было / Стало»** (пунктирный эталон и процент резолюции `ST`), **экспорт в PNG** (`чистая` без диагноза / `с разбором`) и **печать А4**.
- **Шпаргалка для рентгеноперационной**: ключевые критерии ЭКГ, реципрокные изменения, риски на столе ЧКВ (инфаркт ПЖ и запрет нитратов, АВ-блокады, дэмпинг ствола ЛКА, запрет стресс-тестов при Велленсе, экстренное ЧКВ при де Винтере) и дифференциальные мимики.
- **Тёмная тема интерфейса:** переключатель `Светлая / Тёмная` в верхней панели с автоопределением `prefers-color-scheme: dark`, мгновенной инициализацией без мерцания (`index.html`) и сохранением выбора в `localStorage` (`cardioatlas.theme.v1`); миллиметровая бумага ЭКГ, печать А4 и флюороскопический фон С-дуги сохраняют клинически достоверный контраст.

## Быстрый старт

Требуется установленный Node.js 22+ (включая инструменты мобильной сборки).

```powershell
# 1. Установка зависимостей (однократно)
npm install

# 2. Запуск веб-версии в режиме разработки
npm run dev -- --port 5173

# 3. Автоматические тесты ядра, ЭКГ, локализатора, тренажёра и 3D-модели
npm run test:core
npm run test:ecg
npm run test:clinical
npm run test:training
npm run test:heart

# 4. Проверка типов и production-сборка в папку dist/ (включает генерацию sw.js)
npx tsc --noEmit && npm run build

# 5. Запуск десктопного окна Electron локально
npm run electron:start

# 6. Сборка автономного Portable .exe для Windows (выход в release/)
npm run dist:win

# 7. Синхронизация и сборка отладочного Android APK (см. docs/ANDROID_BUILD.md)
npm run android:sync
npm run android:apk
```

- Для работы в браузере откройте `http://localhost:5173/`.
- Для установки на iPhone (PWA): откройте опубликованную страницу на GitHub Pages (`https://tuber84.github.io/infarct_miocard_ecg/`) в Safari → «Поделиться» → «На экран „Домой“».
- Для автономного запуска на Windows без браузера и Node.js используйте исполняемый файл `release/CardioAtlas-ECG-1.0.0-Portable.exe` (пересобирается командой `npm run dist:win`).

## Дорожная карта развития

- **Выполнено:**
  - Классический ИМпST (8 территорий + норма, правый/левый тип кровоснабжения), 12/17-канальная ЭКГ, кардиомонитор и калипер.
  - Интерактивный режим КАГ (С-дуга) с проекциями, болюсом контраста, справочником, 3D-ориентирами флюороскопии (позвоночник, лёгкие, диафрагма) и межсистемными коллатералями Rentrop (`0–3`).
  - Сегментированные 3D-модели правого и левого типов кровоснабжения (`heart_segmented.glb`, `heart_artery_left_type.glb`), панорамирование ПКМ, настраиваемые 3D-подписи артерий.
  - Поддержка ИМбпST (NSTEMI): субэндокардиальные депрессии, примеры ИМбпST без Q, синдром Велленса A/B, паттерн де Винтера (с отдельным описанием стадий), ствол ЛКА, а также распознавание по `T↓` в локализаторе и синхронизация `nstemi_inf` с левым типом кровоснабжения.
  - Блокады и мимики STEMI: БЛНПГ + ОИМ (критерии Сгарбосса/Смита), неосложнённая БЛНПГ, острый перикардит, СРРЖ (J-notch) и синдром Такоцубо.
