# КардиоАтлас ЭКГ — Локализатор ОКС (ИМпST / ИМбпST) и 3D-тренажёр

Локальное оффлайн веб- и десктопное (Windows `.exe`) приложение для врачей — в первую очередь рентгенэндоваскулярных хирургов, кардиологов и реаниматологов — для наглядной отработки взаимосвязи:
**«поражение коронарной артерии → зона ишемии миокарда → 12/17-канальная ЭКГ → динамика во времени и эффект ЧКВ»**.

Поддерживает как **классический ИМ с подъёмом ST (ИМпST / STEMI)**, так и **ИМ без подъёма ST (ИМбпST / NSTEMI)** и особые паттерны при подозрении на окклюзирующее поражение (Велленс A/B, де Винтер, распространённая ишемия).

---

Медицинская основа по выбору автора — **российские клинические рекомендации 2024 года** по ИМпST и ОКСбпST (публикации 2025 года из `ref/gudelines/`). Условия сроков КАГ/ЧКВ, пороговые критерии и ссылки отображаются в клиническом разборе. ACC/AHA используются только для сравнения в [медицинском аудите](docs/MEDICAL_AUDIT_2026-11-21.md). Обновление аудита от 22.11.2026 фиксирует исправление согласованности J/ST и интервалов; клиническая валидация морфологии остаётся отдельной задачей.

Проверка независимости и сценариев: `npm run test:core`. Проверка локализатора: `npm run test:clinical`. Проверка генератора: `npm run test:ecg`.

**Направление развития:** сначала автономный десктоп на Electron, затем мобильная версия с отдельной компоновкой и общим ядром на TypeScript. React и текущую графику сохраняем; Capacitor — кандидат для мобильной упаковки, выбор подтвердим прототипом на телефоне. Архитектурные границы, этапы и критерии готовности описаны в [плане архитектуры и развития](docs/ARCHITECTURE_ROADMAP.md).

Android-проект на Capacitor подготовлен; отладочный APK собран и первоначальная версия опробована пользователем на телефоне. Новое масштабирование жестом ещё предстоит проверить на устройстве. Команды и требования: [сборка Android](docs/ANDROID_BUILD.md).

## Возможности текущей версии

- **Узкий режим тренировки:** вкладки «Условия» / «ЭКГ» / «Ответ», горизонтальная прокрутка ленты, быстрый переход к группам отведений, калипер и масштабирование разведением или сведением двух пальцев. Жест проверен в Chromium при ширине 390 px; проверка на телефоне ещё предстоит.

- **Режим «Тренировка»:** «Дежурство №1 · Боль в груди». Пять последовательных этапов, три вопроса, разбор по российским КР, сохранение текущего этапа и последних 20 попыток на устройстве. Диагноз и результаты исследований раскрываются по ходу задачи. Подробнее — [docs/TRAINING.md](docs/TRAINING.md).

- **16 клинических сценариев в двух вкладках (`ИМпST (STEMI)` и `ОКСбпST / паттерны`)**:
  - **ИМпST (8 сценариев):** `ПМЖВ (LAD)` прокс./сред./длинная, `D1` («флаг ЮАР»), `ПКА (RCA)` прокс./дист., `ОВ (LCx) / ВТК (OM1)`, `Задний ИМ` (ЗБВ ПКА / дист. ОВ).
  - **ИМбпST и эквиваленты (7 сценариев):** `ИМбпST передне-боковой` (субэндокардиальная депрессия ST), `ИМбпST нижне-боковой` (депрессия ST + инверсия T), `ИМбпST с T↓` (глубокая симметричная инверсия T), **синдром Велленса тип A** (двухфазный `+ / −` T в `V2–V4`) и **тип B**, **паттерн де Винтера** (косовосходящая депрессия точки J + острые симметричные T и `ST↑` в `aVR`), **ствол ЛКА (`LMCA`) / 3-сосудистое поражение**.
  - Плюс базовый профиль **`Норма`** (`TIMI 3`).
- **Интерактивная 3D-модель сердца и коронарных сосудов**:
  - Кликабельные точки поражения прямо на ветвях коронарного русла (с автоматической дедупликацией при совпадении сегментов для ИМбпST).
  - Визуализация степени нарушения кровотока в 3D и в КАГ:
    - **`Окклюзия · TIMI 0`** — красный 3D-тромб, синюшное дистальное русло и полный обрыв контраста («культя»).
    - **`Субокклюзия · TIMI 1–2`** — янтарный маркер, приглушённое русло в 3D и замедленное тусклое дистальное контрастирование в КАГ.
    - **`Крит. стеноз · TIMI 2–3`** — янтарный маркер и сохранённое прохождение контраста при ЧКВ-готовности.
    - **`ЧКВ · Стент · TIMI 3`** — металлический 3D-стент и восстановленный кровоток.
  - **Режим КАГ (С-дуга / флюороскопия):** рентген-тень сердца, селективная катетеризация (`ЛКА / ПКА / Обе`), анимация болюса контраста, живая индикация углов С-дуги (`LAO/RAO`, `CRA/CAU`) с двухосевой SVG-схемой трубки и детектора, 10 стандартных проекций КАГ и справочник со сравнительными таблицами.
  - **Удобная навигация и подписи:** `ЛКМ — вращать`, `ПКМ — перемещать` (панорамирование по экрану без сбивания углов С-дуги), `Колесо — зум`, кнопка **`Центр`**, а также 3-режимная кнопка подписей артерий (**`Подпись`** → **`Подписи выкл.`** → **`Все подписи`**) с мягким масштабированием по зуму (`0.7×–1.25×`).
- **Двусторонняя связь «Сосуд ↔ ЭКГ»**:
  - **ЭКГ → Артерия (обратный локализатор):** 4-шаговый клик по карточкам отведений (`1 = ST↑`, `2 = ST↓`, `3 = T↓`, `4 = сброс`) сопоставляет разметку с учебными сценариями и рекомендует дополнительные отведения (`V3R–V4R`, `V7–V9`). При недостаточных данных гипотеза отсутствует; процентов вероятности нет. Велленс B допускает вовлечение V6. Велленс A и де Винтер изучаются в пресетах; ограниченный ввод ST↑/ST↓/T↓ не позволяет автоматически различить их морфологию.
- **Учёт типа коронарного кровоснабжения**: переключатель `Правый тип` / `Левый тип` перестраивает ЭКГ-профиль и границы бассейнов ПКА/ОВ на 17-сегментной схеме AHA.
- **Bullseye AHA-17 и динамика во времени**:
  - Окраска миокарда и варианты без Q заданы условиями учебных примеров; отсутствие Q не обязательно для ИМбпST. Пояснения к срочности КАГ/ЧКВ и критериям ЭКГ — по российским клиническим рекомендациям 2024 года, с указанием разделов.
  - 5 стадий (`Острейшая 5–20 мин`, `Острая 20 мин – 6 ч`, `Эволюция 6–24 ч`, `Подострая 2–7 сут`, `Рубец > 1 мес`), плавный слайдер и сравнение с течением **после ранней успешной реперфузии (TIMI 3)**; интервалы стадий условные.
- **Реалистичный рендер ЭКГ**:
  - **Монитор реального времени** (`1 / 3 канала`, `Стоп-кадр`, маркер реперфузионного ритма `РИА / AIVR`).
  - **12-канальная миллиметровая лента** (`3×4 + ритм II` и `6×2`, `10 / 5 мм/мВ`, `25 / 50 мм/с`, зум `75–160%`, полоса `+ V3R/V4R, V7–V9`, симуляция артефактов, регулировка ЧСС) и встроенный **Калипер** для измерения `Δt (мс)`, расчётной ЧСС и вольтажа.
- **Шпаргалка для рентгеноперационной**: ключевые критерии ЭКГ, реципрокные изменения, риски на столе ЧКВ (инфаркт ПЖ и запрет нитратов, АВ-блокады, дэмпинг ствола ЛКА, запрет стресс-тестов при Велленсе, экстренное ЧКВ при де Винтере) и дифференциальные мимики.

## Технологический стек

- **Frontend:** React `18.3`, TypeScript `5.6`, Vite `5.4`, Tailwind CSS `3.4`, Lucide Icons
- **3D-графика:** Three.js `0.169`, `@react-three/fiber` `8.17`, `@react-three/drei` `9.114` (`GLTFLoader` + оптимизированный `.glb` + текстура `.webp`)
- **2D ЭКГ и визуализация:** HTML5 `Canvas` (DPR-aware) и SVG (AHA Bullseye + мини-комплексы)
- **Desktop (Windows x64):** Electron `45.4` + `electron-builder` `26.18` (автономный Portable `.exe` без установки, подробнее в [docs/DESKTOP_BUILD.md](docs/DESKTOP_BUILD.md))

## Быстрый старт

Требуется установленный Node.js 22+ (включая инструменты мобильной сборки).

```powershell
# 1. Установка зависимостей (однократно)
npm install

# 2. Запуск веб-версии в режиме разработки
npm run dev -- --port 5173

# 3. Проверка типов и production-сборка в папку dist/
npx tsc --noEmit && npm run build

# 4. Запуск десктопного окна Electron локально
npm run electron:start

# 5. Сборка автономного Portable .exe для Windows (выход в release/)
npm run dist:win
```

- Для работы в браузере откройте `http://localhost:5173/` (можно закрепить как PWA через `public/manifest.webmanifest`).
- Для автономного запуска на Windows без браузера и Node.js используйте готовый исполняемый файл `release/CardioAtlas-ECG-1.0.0-Portable.exe` (пересобирается командой `npm run dist:win`).

## Дорожная карта развития

- **Выполнено:**
  - Классический ИМпST (8 территорий + норма, правый/левый тип кровоснабжения), 12/17-канальная ЭКГ, кардиомонитор и калипер.
  - Интерактивный режим КАГ (С-дуга) с проекциями, болюсом контраста и справочником.
  - Оптимизация геометрии сердца в `.glb` + WebP, панорамирование ПКМ, настраиваемые 3D-подписи артерий.
  - Поддержка ИМбпST (NSTEMI): субэндокардиальные депрессии, примеры ИМбпST без Q, синдром Велленса A/B, паттерн де Винтера, ствол ЛКА, а также распознавание по `T↓` в локализаторе.
  - Автономная сборка Portable `.exe` для Windows на базе Electron.
- **Следующие этапы:**
  1. Основа выделена: независимое ядро, разделение медицинских профилей и 3D, структура сценариев. Учебные переходы первого случая реализованы на основе этого контракта.
  2. Первый десктопный кейс и сохранение попыток реализованы. Следующая проверка — врачебная рецензия содержания и удобства прохождения.
  3. Проверить этот же кейс на реальном телефоне с отдельным мобильным интерфейсом, калипером и работой без интернета; по результатам выбрать оболочку.
  4. Расширять каталог и повторение ошибок. Направления содержания: мимики и сложная проводимость, реальные записи ЭКГ (возможный источник — PTB-XL), уточнение 3D-анатомии (см. [docs/3D_MODEL.md](docs/3D_MODEL.md)).

Подробный план и статус решений — [docs/ARCHITECTURE_ROADMAP.md](docs/ARCHITECTURE_ROADMAP.md). Мобильная версия пока не реализована. Режим обучения содержит один случай; каталог задач и интервальное повторение ошибок — последующие этапы.
